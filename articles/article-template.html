PID controllers are everywhere in embedded systems — motor drives, temperature regulators, flight controllers. But most tutorials just give you the formula. Let's derive it properly.

Background: The Error Signal

The fundamental idea is simple. You have a setpoint \(r(t)\) and a measured output \(y(t)\). The error is:

e(t) = r(t) − y(t)

Continue explaining... The controller output \(u(t)\) is what you feed to your actuator (PWM duty cycle, DAC voltage, etc).

The Three Terms

Proportional

The simplest response: scale the error by a gain.

u_P(t) = Kp · e(t)

Integral

Accumulate error over time to eliminate steady-state offset.

u_I(t) = Ki · ∫₀ᵗ e(τ) dτ

Derivative

React to the rate of change of error.

u_D(t) = Kd · de(t)/dt

Full Transfer Function

C(s) = Kp + Ki/s + Kd·s = (Kd·s² + Kp·s + Ki) / s

Discretizing for a Microcontroller

Your MCU runs at fixed time steps \(T_s\). Use the Tustin (bilinear) transform to map the continuous controller into the z-domain:

s → (2/T) · (z−1)/(z+1)

Implementation in C

Here's a clean, portable implementation. No floating point if you swap the types for Q15/Q31 fixed-point. 

typedef struct {
    float kp, ki, kd;
    float integral;
    float prev_error;
    float integral_limit;   /* anti-windup clamp */
    float dt;               /* sample period in seconds */
} PID;

float pid_update(PID *pid, float setpoint, float measured) {
    float error = setpoint - measured;

    /* Integral with anti-windup */
    pid->integral += error * pid->dt;
    if (pid->integral >  pid->integral_limit)
        pid->integral =  pid->integral_limit;
    if (pid->integral < -pid->integral_limit)
        pid->integral = -pid->integral_limit;

    /* Derivative (on measurement to avoid derivative kick) */
    float derivative = -(measured - pid->prev_error) / pid->dt;
    pid->prev_error = measured;    /* store measurement, not error */

    return pid->kp * error
         + pid->ki * pid->integral
         + pid->kd * derivative;
}
